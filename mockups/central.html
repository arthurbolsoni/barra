Integração

Cada fonte escreve um arquivo JSON em %LOCALAPPDATA%\barra\central\<fonte>.json; a barra observa a pasta e junta tudo. A skill rotinas do soul e as sessões do Claude só precisam de um passo no fim de cada execução que reescreve o arquivo dele. O Google Agenda é sincronizado por um serviço próprio, que grava agenda.json.

  • evento: bloco com início e fim na faixa "agenda".
  • execucao: ponto na faixa "rotinas", com estado (ok, falhou, rodando, agendada) e o fim do log.
  • pendencia: entra em "Pendências"; com prazo, também em "prazos".
  • rotina: o agendamento em si, para a lista de rotinas mostrar a próxima execução.

Formato

{
  "fonte": "soul",
  "atualizado": "2026-10-23T07:42:10-03:00",
  "itens": [
    { "tipo": "execucao", "id": "rotinas-diarias/2026-10-23",
      "titulo": "Rotinas diárias", "inicio": "2026-10-23T07:30",
      "estado": "ok", "log": "3 tarefas concluídas" },
    { "tipo": "pendencia", "id": "conta-luz",
      "titulo": "Pagar a conta de luz", "prazo": "2026-10-30",
      "acao": { "rotulo": "abrir o site", "uri": "https://example.com" } },
    { "tipo": "rotina", "id": "backup-fotos",
      "titulo": "Backup das fotos", "quando": "dias úteis 09:00" }
  ]
}
// pendência marcada como concluída é gravada em acoes.jsonl e aplicada pela fonte na execução seguinte
